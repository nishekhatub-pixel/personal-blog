# R7 Personal Garden V2 后台指南

后台入口为 `/admin/login`。所有受保护页面、Server Actions 和上传 API 都在服务端验证管理员会话。

## 导航

V2 后台包含：

```text
概览 / 文章 / 分类 / 标签 / 项目 / 说说 / 相册 / 照片 /
音乐 / 歌单 / 留言墙 / 友链 / 媒体 / 评论 / 设置
```

概览中的文章、项目、说说、相册、照片、音乐、待审核评论、待审核留言和友链申请均来自数据库实时统计。

## 城市、天气和时区

在“设置 → 天气和位置”填写：

- `locationName`：只填写公开城市名，例如“广州”；
- `latitude` / `longitude`：城市级坐标；
- `timezone`：IANA 时区，例如 `Asia/Shanghai`；
- `weatherEnabled`：是否公开天气卡。

公开页面不会请求浏览器精确定位，也不会显示经纬度。天气失败时首页仍正常显示。

## 花瓣

在“设置 → 外观”使用：

- `petalsEnabled`：全局允许/关闭；
- `petalsDensity`：低、中、高。

访客还可使用导航中的花瓣按钮单独关闭，选择保存在当前浏览器。减少动态效果开启时，无论设置如何都不渲染花瓣。

## 相册与照片

1. 在“相册”创建名称、Slug、说明、记录日期和可选城市。
2. 保存后进入相册编辑页，在“批量添加照片”一次选择多张图片。系统会逐张复用安全媒体上传，并为成功项建立真实 `Photo` 草稿。
3. 使用相册编辑页的上移/下移立即保存展示顺序；进入单张编辑页补充 Alt、说明、拍摄时间和可选地点。
4. 也可以先在媒体库上传，再从“照片”单独建立记录。
5. 设置相册封面，先预览，再发布照片和相册。

批次中的单张失败不会回滚已经成功的照片。若图片已进入媒体库但照片草稿创建失败，原媒体会保留，便于修正后重新关联。

公开相册只显示“相册和照片都已发布，且发布时间不晚于当前时间”的记录。删除相册会删除照片关系记录，但不会自动删除媒体库原文件。

## 说说

“说说”支持草稿、发布、归档、置顶、心情、天气和最多 9 张媒体。正文最长 1000 字。

公开说说评论默认待审核。管理员可在说说编辑/审核区域通过、隐藏、标记垃圾或删除。邮件与 IP 哈希不出现在公开页。

## 音乐

### 本地上传

音乐编辑器先通过独立音频上传器上传，再保存曲目。支持：

- MP3；
- M4A/AAC（以浏览器支持为准）；
- OGG。

默认上限由 `AUDIO_UPLOAD_MAX_BYTES` 控制。上传会同时检查声明 MIME、扩展名、文件签名、体积和安全路径。请只上传自己创作、已获授权或明确允许公开的音频。

### HTTPS 直链

远程地址必须是合法公开 HTTPS URL。系统不会抓取、下载或代理该 URL；可用性和版权仍由管理员负责。

### 歌单

创建歌单后加入已存在曲目，并为每一项设置唯一顺序。公开播放器不会自动播放，访客必须主动点击。

## 留言墙

新留言状态固定为“待审核”。审核选项：

- 已通过：公开显示；
- 已隐藏：保留但不公开；
- 垃圾：不公开；
- 删除：永久删除；
- 置顶：只对已通过留言有公开意义；
- 管理员回复：可选，公开显示。

不要在回复中复述隐私信息。

## 友链

访客申请保存为草稿，不会自动公开。管理员核验 URL、名称、简介、头像和联系方式后，可以：

- 编辑；
- 排序；
- 设为精选；
- 发布；
- 归档/隐藏；
- 删除。

联系方式只用于审核，不在公开卡片显示。

## 站点设置分组

- 基本信息：站名、副标题、上线日期、公告。
- 个人资料：R7 名称、简介、头像、当前状态。
- 外观：花瓣与密度。
- 天气和位置：城市、坐标、时区和开关。
- 音乐：公开音乐开关。
- 互动功能：留言、友链、评论和订阅。
- 社交链接：真实 GitHub 和邮箱。

空值不会用假链接补齐。头像、GitHub 和邮箱未配置时，公开资料卡不显示对应入口。

## SQLite 与 MySQL

本地 SQLite：

```bash
pnpm db:generate
pnpm db:deploy
pnpm db:seed
pnpm dev
```

生产 MySQL 必须使用 `prisma/schema.mysql.prisma`、MySQL 增量 SQL 和持久上传存储。完整升级与回滚流程见 [V2 数据库迁移](v2-database-migration.md)。
