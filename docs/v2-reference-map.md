# R7 Digital Garden V2 参考图映射

目录：`design-references/v2-personal-garden/`

## 使用原则

- 参考图是版式、层级、节奏和组件关系的来源，不是生产数据来源。
- 图中出现的日期、数量、天气、城市、阅读量和更新时间都不能硬编码。
- 图中出现的示意媒体不作为 R7 的真实照片、封面或音乐内容。
- 实现时不把整张参考图作为页面背景，也不裁切参考图充当真实组件。
- 页面文案以数据库、SiteSetting 和本文件中的校正规则为准。
- 公开页面没有真实照片、音乐和友链时保持完整空状态。

## 01 首页桌面

文件：`01-home-desktop.png`

- 页面：`/`
- section：完整 1440px 首页
- 核心组件：顶部导航、站点动态条、个人资料、真实统计、快捷入口、时钟、站点统计、欢迎卡、混合内容流、音乐播放器、天气回退、内容日历
- 数据来源：
  - 个人资料与动态条：`SiteSetting`
  - 文章、项目、说说、照片数量：Prisma 实时统计
  - 内容流：已发布的 Post、Project、Moment、PhotoAlbum、MusicTrack
  - 时钟：配置时区 + `Intl.DateTimeFormat`
  - 天气：服务端天气 Route Handler
  - 日历：当前月文章、说说、照片和项目更新时间
- 桌面行为：`252px minmax(0,1fr) 296px` 三栏，约 20px 间距；主内容最宽；视口足够高时左右栏 sticky
- 移动行为：严格单列，个人资料最先，音乐与天气可在 430px 双列，日历独占一行
- 动效意图：动态条缓慢传达站点状态；欢迎关键词轻微位移；按钮提供按压反馈；花瓣只营造空气感
- 实现校正：
  - 图中数量、日期、城市、文章标题和项目进度都是版式占位，生产必须查询真实数据
  - 不使用图中的示意笔记本照片冒充 R7 内容
  - 搜索与主题控件沿用项目真实图标

## 跨图提取结果

### 布局

- 页面最大宽度：1400px 至 1460px
- 桌面主要间距：18px 至 22px
- 普通页面边距：`clamp(1rem, 3.4vw, 3.5rem)`
- 首页三栏：约 `252px / minmax(0, 1fr) / 296px`
- 正文行长：60ch 至 68ch

### 类型层级

- 中文正文继续使用项目现有系统无衬线栈
- 大标题依靠字重、字距和留白，不依靠随机字体混搭
- 时钟、代码与极短元信息使用等宽字体
- 首页 H1 紧凑，不超过两行

### 形状

- 主面板：18px
- 次面板和媒体：12px
- 输入与小控件：8px 至 10px
- 主要按钮：胶囊
- 不为纯文字段落强行添加容器

### 颜色

- 浅色：暖象牙背景、奶油表面、暖炭黑文字
- 深色：暖炭黑背景、深咖啡表面、柔和米白文字
- 唯一主要强调：琥珀
- 成功：低饱和鼠尾草
- 阴影：带暖棕色温，避免纯黑

### 动效

- 只动画 transform 与 opacity
- 无限动画限定为慢速动态条、播放中的唱片、技术轨道和少量花瓣
- 所有无限动画支持 `prefers-reduced-motion`
- 后台和表单密集页不出现氛围动画

## 最终实现优先级

1. 真实数据与空状态。
2. 首页和独立页面的信息层级。
3. 响应式与可访问性。
4. 深浅主题材质。
5. 克制的动效细节。
