# R7 数字花园后台使用指南

后台入口为 `/admin/login`。除登录页外，所有 `/admin` 路由都要求 `ADMIN` 角色和有效会话。

## 本地启动与默认登录

首次启动本地环境：

```bash
pnpm db:generate
pnpm db:migrate
pnpm db:seed
pnpm dev
```

打开 [http://localhost:3000/admin/login](http://localhost:3000/admin/login)，使用当前本地 `.env` 中的开发账号：

```text
邮箱：admin@r7.local
密码：R7-Local-2026-Change-Me
```

这组凭据仅供本地开发。不要把它用于公开部署，也不要将 `.env` 提交到版本库。Seed 会读取 `ADMIN_EMAIL` 和 `ADMIN_PASSWORD`，使用 bcrypt 成本因子 12 保存密码哈希，不会把明文密码写入数据库。

若修改了本地管理员凭据，更新 `.env` 后重新运行：

```bash
pnpm db:seed
```

Seed 会更新管理员密码，同时也会重新同步内置演示内容。对已有正式内容执行前，应先备份数据库。

## 后台导航

桌面端使用左侧导航，移动端使用顶部抽屉和底部快捷导航。右上角可切换浅色或深色主题，也可在新标签页查看公开网站。

后台概览展示真实数据库中的文章、项目、待审核评论、浏览次数和最近活动，不是演示指标。

## 文章管理

### 创建与编辑

进入“文章”，选择“新建文章”。编辑页包含以下字段：

- 标题：2 至 220 个字符。
- Slug：2 至 191 个字符，只能使用小写字母、数字和连字符，例如 `mysql-index-notes`。
- 摘要：20 至 500 个字符。
- 正文：Markdown，至少 50 个字符，最大 300,000 个字符。
- 分类：必选且只能选择一个。
- 标签：最多 20 个。
- 阅读时长：1 至 120 分钟。
- 封面地址与替代文本。
- 推荐状态：控制首页推荐区域。
- SEO 标题与描述。

正文支持 GFM Markdown。桌面端可同时查看编辑区与实时预览，移动端可在“编写”和“预览”之间切换。内容变化后会显示“尚未保存”，离开或刷新页面时浏览器会提醒。

从媒体库复制图片地址后，可在正文中插入：

```md
![准确描述图片内容](/uploads/2026/07/example-1200.webp)
```

### 内容状态

- `草稿`：仅保存在后台，不出现在公开文章列表、搜索、RSS 或站点地图中。
- `发布`：保存后进入公开页面。首次发布会记录发布时间。
- `归档`：从公开内容流中移除，但保留后台记录。

编辑已发布文章时，可从页面右上角打开公开页面检查最终效果。

### 删除文章

删除前会显示二次确认。删除是永久操作，文章及其关联数据会按数据库关系处理。执行前确认内容不再需要，并保留必要备份。

## 项目管理

进入“项目”可搜索、按状态筛选、创建、编辑或删除项目案例。

项目编辑器包含：

- 项目名称、Slug 和一句话摘要。
- Markdown 案例正文，建议依次写清背景、目标、技术取舍、实施过程、结果和复盘。
- 技术栈：每行一项，最多 30 项。
- 画廊地址：每行一个图片地址，最多 20 张。
- 封面地址与替代文本。
- 在线演示与源代码地址：外部链接必须使用 HTTPS。
- 标签、推荐状态、发布状态和 SEO 信息。

项目的 `草稿`、`发布`、`归档`含义与文章一致。发布后可从编辑页打开公开案例。

## 分类管理

分类是文章的主结构，一篇文章必须属于一个分类。

创建分类时填写名称、唯一 Slug 和可选描述。已有分类可在列表中展开编辑。

仍有关联文章的分类不能删除。先把这些文章迁移到其他分类，再执行删除。

## 标签管理

标签可同时关联文章与项目，适合表达技术、主题和长期兴趣。

标签名称和 Slug 必须唯一。删除标签只会移除标签及其关联关系，不会删除文章或项目。为避免重复，创建前先搜索已有标签，并保持命名颗粒度一致。

## 媒体库

### 上传规则

媒体上传支持点击选择和拖放，并显示实时进度与错误信息。当前限制为：

- 格式：JPEG、PNG、WebP、AVIF、GIF、TIFF、HEIC 和 HEIF。
- 后台上传界面最大体积：100 MB。
- 服务端上限由 `UPLOAD_MAX_BYTES` 控制，默认及最高配置值均为 100 MB。
- 图片像素总量上限：100,000,000；超过后会安全拒绝，不会继续解码。
- 文件扩展名、浏览器声明的 MIME 和文件真实内容必须一致。
- 替代文本为 2 至 255 个字符。当前上传界面会用文件名生成初始替代文本，因此上传前应使用简洁、可描述画面的文件名。

图片会自动旋转到正确方向，转为 WebP，并按原图尺寸生成不放大的 320、640、1200、2000 像素宽版本。文件保存在：

```text
public/uploads/YYYY/MM/
```

媒体库记录的是最大可用版本，响应式版本信息同时保存在数据库中。可使用“复制地址”把图片加入文章或项目。

### 删除媒体

删除媒体会同时删除数据库记录和磁盘上的全部响应式版本，无法从后台恢复。系统不会自动改写已经引用该地址的文章或项目；删除前应先检查引用，否则公开页面会出现失效图片。

生产环境必须为 `public/uploads` 配置持久化存储和备份。短生命周期容器或无持久磁盘的 Serverless 文件系统不适合直接保存上传文件；这类环境应改接对象存储。

## 评论审核

评论页支持按关键词、文章和状态筛选。状态含义：

- `待审核`：新评论的默认状态，公开页面不可见。
- `已通过`：允许在文章页公开显示。
- `已隐藏`：保留记录，但不公开显示。
- `垃圾评论`：标记为恶意或无关内容，不公开显示。

每条评论可直接通过、隐藏、标记为垃圾评论或永久删除。删除前会二次确认。审核时不要公开读者邮箱，也不要把评论中的个人信息复制到文章或日志。

## 站点设置

设置页用于维护：

- 站点名称、公开 URL 和站点描述。
- 作者显示名称、简介、联系邮箱和 GitHub 地址。
- 页脚短句。
- Now 页面当前状态。
- 公开评论和邮件订阅开关。

生产环境的站点 URL 必须使用实际 HTTPS 域名。修改描述和作者信息后，应同时检查首页、About、Now、页脚和搜索引擎元数据。

功能开关会保存到数据库。关闭评论或订阅前，应确认公开表单和已有数据的处理方式符合当前运营计划。

## 发布前检查

每次发布文章或项目，至少完成以下检查：

1. Slug 唯一、稳定且没有拼写错误。
2. 标题、摘要和正文完整，没有测试文字或敏感信息。
3. 分类与标签准确，推荐内容数量合理。
4. 封面可加载，替代文本描述图片用途而非重复文件名。
5. Markdown 标题层级连续，代码块注明语言，链接可访问。
6. 外部演示和源代码链接使用 HTTPS。
7. SEO 标题和描述清楚，没有关键词堆叠。
8. 编辑器预览无误，发布后再检查公开详情页。
9. 在桌面与移动尺寸、浅色与深色主题下各检查一次。
10. 键盘可以完成导航、表单操作和主要阅读流程，焦点清晰可见。

## 密码、会话与生产安全

上线前必须完成以下配置：

- 将 `ADMIN_EMAIL` 改为实际管理员邮箱。
- 将 `ADMIN_PASSWORD` 改为独一无二的长密码，建议至少 16 个字符，并使用密码管理器生成和保存。
- 分别生成独立的 `SESSION_SECRET` 与 `IP_HASH_SECRET`，每个至少 32 个高熵随机字符，不要复用管理员密码。
- 将 `APP_URL` 设置为正式 HTTPS 地址。
- 将正式数据库连接写入部署平台的私密环境变量，不要写进代码或镜像。
- 在首次生产 Seed 完成后，从不需要再次 Seed 的运行环境中移除 `ADMIN_PASSWORD`。

登录保护包括：

- 同一 IP 与邮箱组合在 15 分钟内连续失败 5 次后限流。
- 会话令牌只以哈希形式存入数据库。
- 登录 Cookie 为 `HttpOnly`、`SameSite=Lax`，生产模式下启用 `Secure`。
- 会话有效期为 14 天，活动会话最多每天刷新一次最后访问时间。
- 登出会删除当前数据库会话和浏览器 Cookie。

还应执行以下运维措施：

- 强制 HTTPS，并在反向代理层配置安全响应头与请求体大小限制。
- 定期备份数据库和 `public/uploads`，并实际演练恢复。
- 不在日志中记录密码、会话令牌、完整 Cookie 或读者邮箱。
- 限制数据库账号权限，生产与开发使用不同凭据。
- 在依赖升级和上线前运行 `pnpm verify`。
- 管理员设备离开时主动登出，不在共享设备保存密码。
- 若凭据疑似泄露，立即轮换密码与两个 Secret，并清理数据库中的现有会话。

当前后台没有管理员密码修改界面。生产初始化前应通过安全环境变量设置密码；后续轮换可临时更新 `ADMIN_PASSWORD` 并执行 Seed，但必须先备份，并注意 Seed 会同步内置演示数据。
