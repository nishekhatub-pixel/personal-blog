# R7 Personal Garden V2 内容指南

## 内容原则

这个网站记录正在发生的学习与生活，不把 R7 包装成多年从业者。可以写已完成的课程练习、项目过程、复盘、兴趣和阶段目标；不能补写不存在的公司、工作年限、获奖、旅行、作品、评价或技术成绩。

发布前问三个问题：

1. 这件事是否真实发生或正在进行？
2. 文字是否区分“已经完成”“正在学习”“计划尝试”？
3. 图片、音乐与外链是否有权公开？

## 文章

适合完整知识笔记、问题复盘和长篇学习总结。建议结构：

- 为什么记录；
- 当前理解或问题；
- 代码/查询/设计过程；
- 验证方式；
- 仍不确定的部分；
- 下一步。

标题避免“终极”“精通”“最佳实践大全”等与学生阶段不符的夸张表达。

## 项目

项目详情写真实范围：

- 要解决的问题；
- 实际用户或使用场景；
- 本人完成的部分；
- 真实技术栈；
- 遇到的问题与取舍；
- 已运行的测试；
- 尚未完成的限制。

项目架构动画只在 `technologyJson` 能导出至少三层真实链路时出现，不为简单项目制造复杂架构。

## 说说

说说用于 1000 字以内的短记录，例如：

- 当天复习 Java 数组；
- 开始理解面向对象；
- 整理个人博客；
- 复盘第一个项目；
- 钢琴练习、听歌感受或运动后的短想法。

心情和天气是可选轻标签。不要加入虚构日期、地点、成绩或打卡数据。图片必须来自媒体库。

## 相册与照片

先创建相册，再添加照片。相册应围绕一次真实记录或长期主题，不按随机颜色分组。

- 相册名称：具体而克制。
- 说明：交代为什么保存，不编造故事。
- 城市/地点：可选，只到愿意公开的城市或区域级别。
- Alt：描述照片中可见信息。
- Caption：补充背景，不重复 Alt。
- 拍摄时间：不确定时留空。

没有真实照片时保留空状态，不使用网络随机图代替。

## 音乐

音乐页可以保存：

- 自己有权使用的本地音频；
- 合法公开 HTTPS 直链；
- 喜欢的真实歌曲元信息；
- 钢琴练习记录；
- 听歌随记；
- 有权展示的歌词。

禁止抓取音乐平台、上传盗版文件、复制完整受版权保护歌词，或用虚构热门歌填充。若仅想记录一首歌但没有合法音频，应保留为草稿，或只在其他文字内容中提及。

## 留言墙

留言提交后为待审核。审核时：

- 只通过友善、相关且不泄露隐私的内容；
- 不公开邮箱、IP、User-Agent；
- 删除广告、脚本、冒充和敏感信息；
- 管理员回复只回应公开内容；
- 不把测试留言伪装成真实访客评价。

## 友链

只发布真实访问过、确认愿意互联的站点。检查：

- URL 使用 HTTP/HTTPS，且可以打开；
- 名称、简介和头像属于该站点；
- 联系方式只留后台；
- 推荐状态表达真实偏好；
- 下线或劫持的站点及时隐藏。

## About 与个人资料

可长期更新：

- 软件技术专业学生身份；
- 当前学习 Java、JavaScript、MySQL、数据结构和响应式网页设计；
- 已确认的 PHP + MySQL 博客、Java 图书管理系统和本项目经历；
- 钢琴、唱歌、听歌；
- 篮球、羽毛球、乒乓球和台球；
- 近期目标和状态。

GitHub、邮箱和其他社交入口只有填入真实地址时才显示。不要用 `example.com`、GitHub 首页或 `#` 占位。
